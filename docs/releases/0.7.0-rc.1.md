# 0.7.0-rc.1 — 기능 통합 릴리스 후보

후보 지정일: 2026-09-21. 기반 소스 체크포인트: `v0.6.2`.

이 버전은 안정판 0.7.0이 아닙니다. 2026-09-21에 조기 생성된 `v0.7.0` 태그는 필수 릴리스 게이트가 남은 상태였으므로 폐기하고 이 RC로 정정합니다.

## 통합 범위

- 0.6.2의 Custom MOTIS 빌드·검증 소스와 responsive execution 개선을 포함합니다.
- 기존 `codex/0.6.2-main-integration`의 시나리오 계약, 다중 노선 편집·저장·실행·비교, 좌표 A–B job 및 보행 결과 UI를 통합했습니다.
- 기존 `codex/0.6.2-scenario-comparison`의 수요 추정 artifact 로딩과 경계 검증, 실패 provenance 수정까지 포함했습니다.
- 기존 미커밋 빌드 수정과 실증·인수인계·아이디어 문서를 보존했습니다.

## 현재 검증

- 소스 검증: `npm test` 77개 파일 / 438개 테스트 통과
- TypeScript 및 Electron production build 통과
- Windows 설치 패키지와 검증된 Custom MOTIS asset을 사용한 최종 통합 실증은 포함하지 않음

Custom MOTIS 후보의 전국 PBF·BUS·좌표 A–B·문제 노드 FOOT·33-way 거부 실증은 [기존 후보 검증 기록](../test-reports/2026-09-21-msvc-candidate-validation.md)에 있습니다. 이 기록은 최종 통합본과 동일한 배포 asset을 사용한 안정판 증거가 아닙니다.

## 안정판 승격 전 필수 게이트

- 서로 다른 두 Windows workflow run에서 동일한 source·patch·toolchain·binary·payload·archive를 입증
- 두 proof와 전국 PBF 검증 attestation을 묶어 builder lock을 `probe`에서 `locked`로 승격
- 검증된 Custom MOTIS component asset 발행 및 asset identity 고정
- cache와 로컬 vendor가 없는 fresh clone에서 bootstrap·Windows package·packaged smoke 통과
- 동일 app commit, installer, locked binary, PBF를 사용한 시나리오 실행·좌표 A–B·취소·재열기·수요 추정 통합 검증
- release-readiness 검사와 원격 안정 태그 보호 정책 통과

위 게이트가 모두 닫히기 전까지 `main`은 RC 버전을 유지하고 `v0.7.0` 태그를 생성하지 않습니다. 구체적인 보완 구현은 [릴리스 readiness 계획](../plans/2026-09-21-001-fix-release-readiness-plan.md)을 기준으로 합니다.
