# 0.8.1 — 입력·시나리오 UX 유지보수 릴리스

릴리스일: 2026-09-22. 기반 소스 체크포인트: `0.8.0`.

0.8.1은 사용자가 실제로 입력하고 시나리오를 구성하는 흐름에서 혼잡했던
조작을 정리한 마이너 패치입니다. 데이터 입력 버튼의 우선순위를 명확히 하고,
노선·정류장 선택 검색과 시나리오 지도 레이어 선택을 추가했습니다.

## 포함 범위

- `입력 완료`와 `하차 추정`의 primary/secondary action 구분
- 기존 노선·정류장 검색 picker
- 시나리오 지도 레이어를 `선택 노선`·`변경 정류장`·`전체 정류장`으로 분리
- 기존 프로젝트 schema와 시나리오 저장 호환성 유지

## 다음 마이너 릴리스로 분리한 범위

0.9.0에서는 다음 구조적 변경을 별도 검토·구현합니다.

- STTN과 ROUTESTTN을 중복 제거한 canonical station catalog와 저장 마이그레이션
- 지도 우클릭 기반 신규 정류장 생성과 좌표 검증
- 기존 노선 개편과 신규 노선을 함께 다루는 시나리오 구성
- 현행 기준 지점 간 경로탐색을 시나리오 분석과 분리한 독립 workspace
