# 0.9.0 — 정류장 카탈로그·복합 시나리오·지도 중심 경로탐색 후보

0.9.0은 0.8.1에서 분리한 구조적 기능을 native acceptance와 packaged smoke로 검증하기 위한 로컬 후보입니다.

## 포함 범위

- STTN/ROUTESTTN 계열 입력을 canonical station catalog와 route membership으로 분리
- 기존 v10 프로젝트를 읽고 v11 정류장 catalog 저장 구조로 마이그레이션
- 여러 기존 노선 개편과 여러 신규 노선을 하나의 시나리오에 저장·재개방
- 지도 우클릭 정류장 추가 및 좌표 직접 입력 fallback
- 시나리오와 독립된 현행 네트워크 기준 MOTIS 지도 중심 경로탐색 workspace
- 지도 클릭 또는 정류장 검색 기반 출발·도착 endpoint 선택과 경로 오버레이
- PBF bounded auto-discovery, fingerprint 재사용, 변경 감지, Geofabrik 첫 실행 안내
- `지금 출발`, 빠른 시간 preset, 분리된 날짜·시각 입력
- 입력·MOTIS 화면의 primary action과 고급 설정 문구 정리

## 검증 경계

- 평균 분모, MOTIS fingerprint cache/서버 포트, 준비 단계 progress, 정류장 relevance 검색 보정을 완료했습니다.
- `npm test` 110개 파일·554개 테스트, typecheck, production build, Windows packaging, regular packaged smoke가 통과했습니다.
- packaged native-flow smoke에서 PBF 자동 탐색, 지도 endpoint 선택, 첫 import/server readiness, 동일 네트워크 재검색 cache hit, 결과 카드·지도 표시와 기존 분석·시나리오 흐름을 확인했습니다.
- 상세 결과와 실행 artifact는 [`2026-09-22 0.9.0 feedback correction report`](../test-reports/2026-09-22-v0.9.0-feedback-correction.md)에서 확인합니다.
- PBF 부재 시 Geofabrik 안내는 resolver/renderer 계약 테스트로 확인했으며, 별도 수동 native acceptance는 아직 미실행입니다.
- `npm run release:verify`는 32-way MOTIS validation attestation 부재로 `releaseReady: false`입니다. 원격 push와 최종 0.9.0 승격은 이 gate를 충족한 뒤 별도로 진행합니다.
