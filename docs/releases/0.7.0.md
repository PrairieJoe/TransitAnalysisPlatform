# 0.7.0 — 기능 통합

확정일: 2026-09-21. 기반 태그: `v0.6.2`.

## 통합 범위

- 0.6.2의 Custom MOTIS 빌드·검증 소스와 기존 responsive execution 개선을 포함합니다.
- 기존 `codex/0.6.2-main-integration`의 시나리오 계약, 다중 노선 편집·저장·실행·비교, 좌표 A–B job 및 보행 결과 UI를 통합했습니다.
- `origin/codex/0.6.2-scenario-comparison`의 `134ace4`, `052358d`, `7c0cf3f`, `ad93410`을 병합해 수요 추정 artifact 로딩과 경계 검증, 실패 provenance 수정을 포함했습니다.
- 기존 미커밋 빌드 수정과 실증·인수인계·아이디어 문서를 모두 보존했습니다.
- 과거 문서의 0.6.2 통합 브랜치 명칭은 당시 이력을 의미합니다. 최종 기능 통합 버전 및 재개 기준은 이 문서의 0.7.0입니다.

## 남은 검증

이번 최종 소스 검증: `npm test` 77개 파일 / 438개 테스트 통과, `npm run build` TypeScript 및 Electron production build 통과. Windows 설치 패키지와 실제 Custom MOTIS 통합 실증은 이 검증에 포함하지 않습니다.

Custom MOTIS 후보의 전국 PBF·BUS·좌표 A–B·문제 노드 FOOT·33-way 거부 실증은 [기존 후보 검증 기록](../test-reports/2026-09-21-msvc-candidate-validation.md)에 있습니다. 그 기록은 이번 최종 통합본을 새로 검증한 결과가 아닙니다.

- 독립적인 두 번째 clean MSVC proof observation 확보
- archive/binary/PBF/report hash와 두 observation 검증 후 builder lock을 `probe`에서 `locked`로 승격
- 검증된 Custom MOTIS asset publish 및 fresh-clone bootstrap·Windows package smoke
- 동일 검증 asset으로 최종 0.7.0의 시나리오 실행·좌표 A–B·취소·재열기·수요 추정 통합 검증

MOTIS asset 참조 `v0.6.2`는 Custom MOTIS 배포 기반의 식별자이므로 앱 버전 0.7.0에 맞춰 일괄 변경하지 않습니다. 실행파일·PBF·로컬 대용량 산출물은 Git에 추가하지 않습니다.

## 브랜치 정리 정책

0.6.2와 0.7.0은 각각 `v0.6.2`, `v0.7.0` 태그로 보존합니다. 로컬·원격 main은 0.7.0으로 fast-forward하며, 모든 기존 작업 브랜치의 커밋이 main에 포함된 것을 확인한 뒤 작업 브랜치를 삭제합니다. 로컬 데이터·의존성·실증 산출물은 보존합니다.
