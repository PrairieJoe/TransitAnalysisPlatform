# 0.7.0 — 기능 통합 정식 릴리스

릴리스일: 2026-09-21. 기반 소스 체크포인트: `v0.6.2`.

0.7.0은 0.6.2의 32-way Custom MOTIS 기반 위에 시나리오 편집·저장·실행·비교, 좌표 A–B 여정, 보행 결과 UI, 수요 추정과 artifact 경계 검증을 통합한 버전입니다.

## 필수 검증

- 대한민국 전체 PBF에서 32-way Custom MOTIS import, health, BUS route, 문제 노드 FOOT, 좌표 A–B transit을 통과했습니다.
- 공식 16-way control은 18-way 문제 노드에서 실패했고, 33-way fixture는 32-way 경계에서 거부됐습니다.
- `npm test`: 80개 파일, 454개 테스트 통과
- `npm run typecheck`: 통과
- `npm run build`: 통과
- 검증된 `motis-windows-x64-v2.11.3-osr32-msvc-candidate.zip`을 배포 가능한 component artifact로 확인했습니다.
- 동일 artifact의 manifest와 binary를 0.7.0 Windows 패키지에 포함하고 packaged app smoke를 통과했습니다. renderer 예외는 0건입니다.

세부 결과와 해시는 `docs/test-reports/0.7.0-final-readiness.json`, `test-artifacts/motis-validation-attestation.json`, `test-artifacts/motis-component-artifact.json`에 기록되어 있습니다.

## 후속 릴리스 인프라 개선

독립 2회 빌드, builder proof, lock 승격, 공급망 provenance와 fresh-clone bootstrap은 0.7.0의 기능 승격을 차단하지 않습니다. 해당 항목은 후속 릴리스 인프라 개선 과제로 남깁니다.
