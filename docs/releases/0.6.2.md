# 0.6.2 — Custom MOTIS 빌드 기반

확정일: 2026-09-21. 이 버전은 소스 체크포인트이며 Windows 배포 asset의 최종 승인을 뜻하지 않습니다.

## 범위

- v0.6.1 이후 responsive execution, bounded IPC와 프로젝트 목록, 취소·진행률 및 가져오기 경계를 포함합니다.
- 시나리오 브랜치 병합 직전 `8d7a9b5`를 기준으로 Custom MOTIS 소스·MSVC/Ninja 빌더·manifest v2·검증·lock·publish 절차를 보존합니다.
- 한국어 compiler 출력, LF patch 정규화, buildcache 비활성화, 공식 control 로그 판정 수정사항을 포함합니다.
- 시나리오 기능과 좌표 A–B UI, 수요 추정 후속 변경은 0.7.0 범위입니다.

## 남은 배포 검증

이번 소스 확정 검증: `npm test` 61개 파일 / 331개 테스트 통과, `npm run build` TypeScript 및 Electron production build 통과.

lock은 `probe` 상태를 유지합니다. 독립적인 두 번째 clean build observation, hash-bound 증거의 최종 lock 승격, 검증 asset publish, fresh-clone bootstrap 및 Windows package smoke가 필요합니다. 기존 실패 차단 검사를 완화하지 않습니다.

0.7.0은 이 버전을 조상으로 포함하며, 최종 로컬·원격 작업 브랜치는 main 하나로 정리합니다. 이 버전은 `v0.6.2` 태그로 보존합니다.
