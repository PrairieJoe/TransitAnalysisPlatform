# 0.7.1 — TAP/component Release 분리

릴리스일: 2026-09-21.

0.7.1은 TAP 앱 버전을 올리고 Custom MOTIS asset의 수명주기를 TAP 버전과
분리한 유지보수 릴리스입니다. 기존 `v0.7.0` tag와 Release asset은 변경하지
않습니다.

## Custom MOTIS component

- component tag: `motis-v2.11.3-osr32.1`
- 기존 검증 archive를 재빌드하지 않고 그대로 게시
- archive SHA-256: `f4896e578f9acc272295077e9e41e922fb94cb64419455234cc8f32201159ff5`
- `motis.exe` SHA-256: `d91627ab9f74959fb97dd2996c5df610059b565d29f95a1358056a4b7b458bff`
- TAP `motis:prepare`는 TAP 버전 tag가 아닌 위 component tag의 asset을 참조

## Fresh clone 검증

아래 순서를 새 clone에서 실행합니다.

```powershell
npm ci
npm run motis:prepare
npm run build
npm run package:win
npm run test:packaged-smoke
```

검증이 완료되면 TAP `v0.7.1`을 생성하고, 이후 TAP 버전과 Custom MOTIS
component 버전을 독립적으로 관리합니다.
