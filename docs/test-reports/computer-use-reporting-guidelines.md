# Computer-use 보고서 작성 지침

이 문서는 0.6.1 이후 화면 검증 보고서에 적용할 별도 작성 지침이다. 기존 보고서의 내용을 수정하지 않고, 다음 보고서부터 캡처 위치·메모 수준·데이터 범위를 일관되게 관리한다.

## 캡처 위치

- 페이지 최상단을 기본 캡처 위치로 사용하지 않는다. 검증 대상인 지도·차트·표·지표가 화면 중앙에 오도록 먼저 스크롤한다.
- 한 화면 안에서 대상이 접혀 있으면 패널을 펼친 뒤 캡처한다.
- 지도는 마커·흐름선·노선 형상이 식별되는 확대 수준을 사용한다. 지도 제목만 보이는 상태는 증거로 인정하지 않는다.
- 표는 헤더와 검증할 행이 함께 보이도록 수직 스크롤한다. 열이 잘리면 가로 스크롤 후 별도 캡처를 추가한다.
- 중요한 내용이 한 화면을 넘어가면 `상단 요약`, `중앙 시각화`, `하단 상세 표`를 각각 캡처한다. 한 장에 억지로 담아 글자나 지도 요소가 작아지지 않도록 한다.
- 스크롤 전후의 상태가 모두 필요하면 동일 단계 안에서 `전`, `중앙`, `후` 순서로 번호를 부여하고, 각 이미지가 어떤 검증 질문에 답하는지 기록한다.
- 3D 화면은 실제 형상·정류장 점·범례 또는 저장 버튼이 보이는 위치에서 캡처한다. 빈 WebGL 영역이나 전환 버튼만 보이는 화면은 보조 증거로만 사용한다.

## 메모 작성 수준

각 캡처에는 다음 다섯 항목을 바로 붙인다.

1. **검증 조작** — 어느 탭을 눌렀고 어떤 필터·기간·토글을 적용했는지 적는다.
2. **중앙 확인 영역** — 화면의 어느 지도·차트·표를 확인했는지 구체적으로 적는다.
3. **관찰 결과** — 화면에 표시된 실제 숫자·노선 ID·정류장 수·오류 건수를 1개 이상 적는다.
4. **판정** — PASS, FAIL, 관찰, 사용자 확인 필요 중 하나로 표시한다.
5. **사용자 확인 질문** — 운영 기준이나 지도 정합성처럼 자동 판정할 수 없는 항목을 한 문장으로 적는다.

`정상 표시됨`, `화면 확인`과 같은 포괄적인 메모는 사용하지 않는다. 예를 들어 `OD 1,451개 흐름과 좌표 미매칭 21건 안내가 지도 중앙에 보임`처럼 화면에서 바로 대조할 수 있는 문장을 쓴다.

## 이미지 주석

- 가능하면 원본 캡처에 번호, 강조 박스, 화살표를 추가한 주석 이미지를 문서에 삽입한다.
- 강조 박스는 실제 검증 대상의 경계를 감싸고, 메모는 이미지 상단이나 빈 여백에 배치해 데이터 자체를 가리지 않는다.
- 원본 PNG와 주석 PNG를 같은 폴더에 보존한다. 문서에는 주석 PNG를 넣고 캡션에 원본 파일명을 함께 기록한다.
- 주석 번호는 보고서 단계 번호와 일치시킨다. 문서의 본문, 표, 이미지 캡션에서 같은 번호를 사용한다.

## 데이터 범위 기록

- 원본 폴더, 파일명, 기간, 파일별 행 수와 전체 행 수를 보고서 앞부분에 기록한다.
- 전체 원본과 UI 안정성을 위한 축약 프로필을 사용하면 두 범위를 반드시 구분한다. 축약 프로필의 노선·행 수·샘플링 규칙을 적고, 전체 원본 수치를 축약 결과처럼 표시하지 않는다.
- 예: 여수시 2024-04-15~21 DWTCD 원본은 762,499행, 약 109.8MB이다. 화면 캡처용 프로필이 3개 노선 11,550행이면 `화면 검증 프로필`이라고 명시한다.
- 데이터가 적어 보이면 먼저 원본 파일의 행 수와 프로젝트에 실제 적재된 행 수를 비교한다. 프로젝트 카드의 행 수만으로 전체 원본 규모를 판단하지 않는다.
- 축약 프로필을 사용한 경우 전체 원본 재검증이 필요한지 `사용자 확인 필요` 항목에 남긴다.

## 제출 전 체크리스트

- [ ] 모든 분석 항목에 중앙 지도·차트·표 캡처가 있다.
- [ ] 접힌 패널, 하단 표, 3D 형상 등 스크롤 대상이 별도 캡처에 포함됐다.
- [ ] 각 이미지에 조작·중앙 영역·실제 수치·판정·사용자 질문이 연결됐다.
- [ ] 주석 이미지의 번호와 문서 단계 번호가 일치한다.
- [ ] 원본 파일별 행 수와 캡처 프로필의 축약 여부가 기록됐다.
- [ ] DOCX 내부에 이미지가 삽입됐고, 원본 및 주석 PNG가 보존됐다.
- [ ] 문서 구조·접근성 검사와 이미지 수 검사를 수행했다.
