# Seven-day packaged UI validation

Planned input: all DWTCD, STTN and ROUTESTTN files for 2024-04-15 through 2024-04-21. A one-day debug run precedes the full run. All imports occur through the actual DOM file input in a separately launched packaged Electron application with a fresh, isolated profile. Existing user projects are never opened.

Assertions: automatic field mappings are populated; every selected file is previewed; the persisted project covers the requested dates; inference preserves source observations; weekday, OD and route views render; inferred-mode toggles update persisted settings; route 2D/3D switching works; repeated view cycles and reload preserve results. Measure wall time, renderer event-loop stalls and JS heap after view cycles. These are diagnostic observations, not a claim of leak-free operation. No raw card IDs or transaction rows are included in artifacts.

## One-day debug result

Passed against the existing packaged build with 105,412 transactions for April 15. Preserved 26,006 observed destinations; generated 78,219 inferred destinations. OD boardings changed from 25,667 observed to 25,804 high-confidence. Weekday/OD/route navigation, 3D initialization, three view cycles and reload assertions passed without unhandled renderer exceptions.

The corrected harness captures mapping labels/field positions and reads saved manifests outside the renderer instead of repeatedly cloning records through `listProjects` IPC. This avoids test-induced renderer allocation. Result: `test-artifacts/week-ui/2026-09-18T16-44-47.765Z/result.json`. Import 5.04s; inference 6.62s; repeated weekday 1.45–1.58s, OD 2.83–2.96s, route 4.84–5.03s; 3D readiness 0.38s. Renderer timer maximum delay was 2.72s (32 intervals over 100ms): functional completion is not smooth responsiveness. Raw renderer heap grew 227→379→389MB; these uncontrolled-GC snapshots do not demonstrate a leak. The full-run harness additionally collects post-GC measurements.

Initial sandbox launch failed before creating a debug endpoint; authorized elevated execution resolved launch. Only fresh test profiles were used.

## Seven-day result

Passed against the rebuilt 0.6.1 package using seven DWTCD, STTN and ROUTESTTN files for 2024-04-15 through 2024-04-21. The run loaded 762,499 transactions, preserved 200,181 observed destinations and generated 553,534 inferred destinations. OD boardings were 199,037 observed and 199,976 high-confidence; the route expected-flow result contained 761,644 rows. Field mappings, all seven file previews, date coverage, weekday/OD/route navigation, high-confidence and expected-flow toggles, 3D readiness, three repeated view cycles and reload persistence all passed. Renderer errors were 0.

Evidence: `test-artifacts/week-ui/2026-09-19T00-38-53.031Z/result.json`. Import and persist took 36.98s; inference and persist 67.08s; first weekday/OD/route views took 8ms/7.27s/9.05s; repeated cycles were 3.65–10.02s per view. The measured renderer timer maximum delay was 33.8s (60 intervals over 100ms), so the workflow completed but is not a smooth-responsiveness claim. Raw JS heap was about 1.0GiB before collection and stabilized around 525–526MiB after explicit garbage collection across all three cycles; this is diagnostic evidence, not a leak proof. The seven-day input state reports 200,181 observed and 553,534 inferred rows and records all requested dates.
