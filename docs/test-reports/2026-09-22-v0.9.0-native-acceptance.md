## Native checklist

- [ ] PBF가 없는 최초 실행에서 파일 선택창 없이 Geofabrik 다운로드 안내가 표시된다.
- [ ] 권장 routing 위치에 PBF를 둔 뒤 `다시 찾기`로 자동 인식되고 fingerprint가 표시된다.
- [ ] 경로탐색 workspace 진입 즉시 Leaflet 지도와 endpoint 안내가 표시된다.
- [ ] 지도 첫 클릭이 출발지, 두 번째 클릭이 도착지가 되며 검색 선택과 동기화된다.
- [ ] MOTIS 경로 결과가 지도 overlay와 route card에 함께 표시된다.
- [ ] geometry가 없을 때 정류장 좌표 연결선 fallback이라는 안내가 표시된다.
- [ ] `지금 출발`, `+15분`, `+30분`, `+1시간`, 명시적 날짜·시각 입력이 동작한다.
- [ ] 기존 노선 개편과 신규 노선을 함께 저장하고 재개방할 수 있다.
- [ ] 현행 네트워크 독립 경로탐색과 시나리오 비교가 서로 다른 작업공간으로 유지된다.

## Release decision

native checklist와 packaged smoke가 모두 통과하기 전에는 0.9.0을 원격 push하거나
최종 릴리스로 승격하지 않는다. 현재 packaged native-flow는 통과했지만 PBF 부재
수동 acceptance와 32-way MOTIS validation attestation이 남아 있다.

따라서 현재 readiness 판정은 `releaseReady: false`이다.
