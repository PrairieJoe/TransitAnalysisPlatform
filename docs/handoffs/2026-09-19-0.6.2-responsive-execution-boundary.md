# Changes made while resuming

- Route analysis no longer receives the full renderer-side route-stop master over IPC; the main process reads the project-owned metadata instead.
- `ProjectSummary` is now a bounded card/list projection (`recordCount`, `hasRouteMaster`, and identifying metadata). Large route masters and result arrays remain out of `project:list` and `project-summary.json`.
- Main-process jobs can read full metadata without returning records; legacy oversized summary artifacts are normalized when read.
- Analysis tabs become active only after their save/revision update completes, avoiding stale-revision races during fast tab transitions.
- The packaged UI harness caches unchanged JSON files instead of reparsing the full project/state on every polling check, and avoids rerunning an already-active tab.
- The benchmark report version is read from `package.json`, so the current report correctly identifies 0.6.2.
