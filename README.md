# Transit Analysis Platform

교통카드 CSV/DAT/TXT/XLSX 파일을 불러와 요일별 평균 승차인원과 비율을 분석하는 Windows 설치형 데스크톱 앱입니다.

## 주요 기능

- 여러 파일 가져오기와 필드 매핑
- 파일 클릭 또는 드래그앤드롭으로 가져오기
- 상위 10개 행 데이터 미리보기
- 첫 행이 필드명인 파일과 필드명이 없는 파일 모두 지원
- 이용인원 합계/통행량(행 수) 구분 집계
- UTF-8/CP949 계열 텍스트 자동 인식 및 구분자 미리보기
- 실제 관측일/전체 날짜 기준 평균 계산
- 노선·정류장·지역 필터
- 첨부 이미지 형식의 그래프와 표
- PNG·PDF·XLSX 내보내기
- 로컬 프로젝트 저장 및 `.taproj` 백업

## 개발

Node.js 20 이상과 npm이 필요합니다.

```powershell
npm install
npm test
npm run typecheck
npm run dev
```
